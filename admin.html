How publishing works

This is a static website, so the dashboard prepares the updated data file for you. The last two steps are yours:

  1. Make your changes below, then click Download updated videos.js.
  2. Replace js/videos.js in your site folder with the downloaded file.
  3. Push it live:
    git add js/videos.js
    git commit -m "Update video lectures"
    git push

Tip: upload raw video files to YouTube first (Unlisted works fine), then paste the video link here.
